# 三层浏览验证记录

日期：2026-10-28。当前实现采用 TypeScript 5.9.3 与 Python AST/symtable，Joern 不进入运行依赖。系统架构保持默认入口。

## 已交付的行为

- 文件引用、函数上下游、结构化逻辑与变量引用都来自同次源码捕获；JS/TS、Python 同期支持。
- 函数图改为“调用方 → 当前函数 → 被调用方”，默认聚焦一个函数，可切换；包含关系放在结构列表。未解析调用可展开，递归与相互调用有标记。
- 架构按引用方向分层，大项目默认聚焦关联较多的模块，可切换全项目概览；未关联模块独立表达。图的起点仅指本范围的静态引用起点。
- 逻辑图区分函数体开始、分支、返回与抛错；变量视角显示定义和符号引用。异常与异步路径不是完整 CFG，变量连线不是到达定义或真实数据流。
- 修正导航行上下间距为 12px；左右面板可拖动、键盘调整并分别保存宽度；函数选择复用页面内白色自定义菜单。

## 可重复的测试

统一夹具在 `tests/fixtures/code-browser/`，预期在 `expected.json`。回归覆盖导入别名、再导出、构造与方法、递归、闭包、回调未解析、遮蔽、global/nonlocal、解构和多次赋值、类型导入、UTF-16 位置、语法失败、符号表失败、快照隔离、接口认证、过期快照、有界分页及分析失败隔离。

额外反例验证：不能把 TypeScript 的可调用类型/共同调用签名当作已经确定的函数值。条件选择、间接初始化等保留候选；类型导入不产生运行调用目标。JS 解构赋值及 for-in/of 的写入另有测试。

前端模型测试检查有向分层、循环关联、焦点三栏、双向调用的视觉副本与源对象身份、未解析调用折叠，以及语义层级与缩放分离。实际页面另核对源代码联动、返回状态、菜单、分隔条与三个桌面尺寸。最终 68 项 Python 回归、7 项前端模型测试、离线构建与 CLI 有界导出通过。最终测试日志保存在 `.local/code-browser/tests.log`、`frontend-tests.log`；界面验收记录见项目根目录 `design-qa.md`。

## 真实项目实测基线

下面是构建期间冻结快照的测量，不把后续界面修改冒充重新测量，也不将节点数或候选数当作准确率。

| 项目 | JS/TS 索引 | Python 索引 | JS/TS 子进程峰值 RSS | Python 子进程峰值 RSS | 宿主进程峰值 RSS |
| --- | ---: | ---: | ---: | ---: | ---: |
| CodeStrata，`fc47561ac719` | 0.36 s | 0.67 s | 176 MiB | 57 MiB | 130 MiB |
| Future Props Lab，`e51ba8d45eeb` | 19.25 s | 35.39 s | 1.74 GiB | 0.97 GiB | 4.21 GiB |

Future Props Lab 捕获及原扫描约 5.51 s，语义索引及宿主索引组装合计约 58.39 s。每语言进程时限 60 s；JS/TS 的 Node 堆上限 2 GiB。堆上限不等于进程总内存上限。

Future Props Lab 的完整索引 JSON 为 577,417,360 字节，约 551 MiB。浏览器没有加载这份完整语义图，而是按焦点、窗口和关系页查询。当前后端仍常驻完整符号/引用索引，大项目的内存成本较高，适合本地有足够内存的开发环境；后续可将引用存储改为按文件或持久索引加载。不能仅凭有界画布推断后端内存也有同样的小预算。

同一会话内对固定 20 个函数的后端局部查询，Future Props Lab 的 P95 为 JS/TS 约 0.10 ms、Python 约 0.06 ms；三个函数的首次逻辑生成约为 JS/TS 181–275 ms、Python 102–119 ms。这些数字不包括 HTTP、浏览器布局与渲染，不能直接宣称页面端到端延迟。

CodeStrata 的冻结快照包含当时的构建产物；大于 512 KiB 的运行 bundle 被解析预算排除。不同构建版本的节点数量不可直接比较。

## 源码核对

两个项目分别对每种语言核对 20 处调用、10 个变量，共 80 处调用和 40 个变量。调用按 10 个已定位/候选、10 个未解析分层选择，优先产品源码且每文件最多两处；变量每个保留最多 12 处引用。记录含路径、行列、源码片段、哈希、候选目标与逐项判断。

在这些限定样本中，已定位/候选目标与源码声明相符；没有观察到错误的内部目标。未解析样本包括平台/外部库、回调参数、动态接收者和继承实现。候选继续保持候选，不能据此宣称实际运行时会调用该实现。

变量样本核对了声明、保留的读写位置与作用域；引用数较多的变量没有逐条核对全部引用。Python 导入绑定独立记录，不把它与原模块变量合并成同一个可变绑定。

这次检查由 Codex 对照冻结源码完成，不是用户人工批准或运行验证；分层样本不用于计算项目总体精确率、召回率。既没有运行 Future Props Lab，也没有安装其依赖或修改其源码。
